# HealthClarify

HealthClarify is an AI-powered patient empowerment platform designed to improve the readability and understanding of hospital discharge summaries in the context of the European Health Data Space (EHDS).

## Features

- Plain-language translation (CEFR A2)
- Multilingual support
- Local LLM inference (LM Studio / Ollama)
- Medication schedule visualization
- Printable patient summaries
- Emergency red-flag detection
